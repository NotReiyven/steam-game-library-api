Where do I find my SteamID64?

Open Steam, click your name, then Profile. If the address looks like steamcommunity.com/profiles/76561198…, that 17-digit number is your ID and you can paste the whole link above.

If it looks like /id/yourname, paste that link into steamid.io and copy the steamID64 value.

Also set Steam → Profile → Edit Profile → Privacy Settings → Game details = Public, or Steam returns an empty library.

Quick setup
How Backlog Compass works
  1. 1. Get your games in. Add your SteamID64 in Settings and press Sync. For Switch, PlayStation, GOG and others, use Add game in the Library.
  2. 2. Tell it about them. Each game has a priority (how much you want to play it), moods it suits and a typical sitting length. Quick setup on the Today page walks through them one at a time.
  3. 3. Ask what to play. On Today, tap how long you have and the mood you're in. You get a pick and the reasons behind it.
  4. 4. Track it. Set a status (Backlog, Playing, Paused, Completed, Dropped), update progress and log sessions. Steam playtime and your logged sessions are kept separate.
How picks are scored: priority × 20, +25 if the mood matches, +15 if a sitting fits your time (−15 if it doesn't), +10 if you're already playing it, −10 if it's paused. It's a simple planning aid, not an AI.
